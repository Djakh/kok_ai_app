Design a mobile app UI for a ClimateTech product called KOK.AI.

The app gamifies protecting urban trees.
Users explore their city, register real trees using camera and location, earn rewards, track their impact, and share progress with the community.

The experience should feel like Pokémon GO exploration combined with a sustainability app.

Avoid generic sustainability dashboards.
Focus on tree discovery, registration, community engagement, and environmental impact tracking.

COLOR SYSTEM (IMPORTANT)

Use a nature-inspired palette dominated by bright brown and vibrant green.

Primary Green
#4CAF6D

Bright Leaf Green
#6BCB77

Deep Forest Green
#2E7D32

Warm Earth Brown (primary background tone)
#9C7A57

Light Earth Brown
#C49A6C

Neutral Light
#F5F5F5

Design rules:

Primary actions = green
Cards and surfaces = warm brown gradients
Charts = mix of green and brown
Avoid plain white screens
Use earth-tone gradients for backgrounds

Example backgrounds:

brown → light brown gradient
green → leaf green gradient

The interface should visually feel like tree trunk + leaves combined.

APP STRUCTURE

Bottom navigation should contain three tabs:

Dashboard
Map
Profile

Map should not be the home screen, but accessible from Dashboard or via tab.

SCREEN 1 — Login

Elements:

Logo
Email / phone input
Password input
Login button
Register link

Background: warm brown → green gradient.

SCREEN 2 — Register

Inputs:

Name
Email / phone
Password
Confirm password
Optional avatar

Primary button:

Create Account

SCREEN 3 — Dashboard (Home)

Main hub of the app.

Sections:

User impact summary card

Charts showing:

Trees registered
CO₂ impact estimate
Environmental contribution

Quick actions:

Register Tree button
Open Map button

Nearby trees preview map card.

Today's challenge section.

Example:

"Register 2 new trees today"

Leaderboard preview.

Community highlights.

SCREEN 4 — Map

Full screen interactive map.

Features:

User location indicator
Tree markers across map
Floating Register Tree button

Tree marker colors:

Green = healthy tree
Brown = needs attention
Gray = unknown

Markers should look like tree icons.

SCREEN 5 — Register Tree Step 1 (Camera)

Camera interface requiring photos:

Tree front
Trunk close-up
Leaves

Use camera guide overlays.

Button:

Take Photo

SCREEN 6 — Register Tree Step 2 (Location Verification)

User must touch the tree with phone.

Show circular progress animation.

Text:

“Hold your phone close to the tree to confirm location.”

SCREEN 7 — Register Tree Step 3

Optional input:

Tree Name

Example:

Grand Oak
Park Maple

Button:

Register Tree

After submission show animation:

Tree appears on map.

Reward animation with KOK Coins.

SCREEN 8 — Tree Profile

Displays the digital identity of a tree.

Elements:

Tree photo
Location
Guardian name
Health status (AI placeholder)
Activity timeline

Buttons:

Update photo
Report issue
Visit tree

SCREEN 9 — Community

Social feed where users share activity.

Example posts:

"I just registered a new tree in Central Park 🌳"

Features:

Like
Comment
Join challenges

Community leaderboard.

SCREEN 10 — Profile

User information:

Avatar
Guardian level
Trees registered
Coins earned

Tabs:

My Trees
Achievements
Leaderboard

VISUAL STYLE

Nature + technology aesthetic.

Icons should combine:

leaf shapes
tree silhouettes
circuit-like patterns.

Use rounded cards and soft shadows.

Charts should mix green and brown bars.

Map markers should look like small trees with leaves.

Animations:

Tree appearing on map
Coin reward animation
Progress circle during location verification.

GOAL

Design a gamified environmental exploration app that motivates people to walk around their city and register trees while contributing to a global tree database.
